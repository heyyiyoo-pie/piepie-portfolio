# 撇撇的作品集

静态作品集网站，入口为 `index.html`，图片与字体位于 `assets/`。包含 8 个项目和 21 张详情图。

## 发布

GitHub Pages 使用 main 分支的根目录。更新网站文件并推送到 main 后，Pages 自动重新发布。

正式地址：https://piepie-portfolo.me 。自定义域名保存在 CNAME，发布时保留该文件。

## 交互

首页卡片自动匀速播放；触摸左右滑动可快速切换，松手后继续播放。项目详情顶部不重复显示首页封面。首屏直接显示撇撇的名字与头像。
